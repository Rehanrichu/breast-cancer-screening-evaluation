# References and data source

## Dataset

The project uses the Wisconsin Diagnostic Breast Cancer dataset distributed with scikit-learn. It is loaded directly through `sklearn.datasets.load_breast_cancer`; no external data file or patient-level download is needed to run the code.

- Scikit-learn dataset documentation: https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_breast_cancer.html
- Original dataset citation as referenced by scikit-learn: Wolberg, W. H., Street, W. N., and Mangasarian, O. L., Wisconsin Diagnostic Breast Cancer dataset.
- UCI Machine Learning Repository page: https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic
